<Callout variant="proposition" title="Proposition 1">
A proposition is a statement that is true or false
(Although every statement is true but here no it depends).
</Callout>

Example of propositions:
\sum^10_{i=1} i = 50 <- thats a FALSE proposition
\prod^5_{i=-5} i = 0 <- that's a TRUE proposition
Zip codes in USA have exactly 7 digits. <- that's a FALSE proposition
For all integers x, 2x is an even #. <- that's a TRUE proposition

All of them are propositions.

---
Examples that are NOT propositions:

for integer x, x+1 is even <- NOT a proposition (because it depends on x)
7*8 <- NOT a proposition (because it's incomplete)
x^2 +1 = 2 <- NOT a proposition (because it depends on x)
Atlanta airport is busiest airport in USA <- NOT a proposition (because it's debatable on what "busiest" means)

for all V x in Z, 2x is even <- that's a TRUE proposition
\forall x \in Z, 2x is odd <- false prop
\forall x \in Z, 2x > x <- false prop
(so before the x is not defined / not qunatified , but here x is defined for every integer, we can proof it's false so it's a proposition)
by showing a counter example
opposite : \exists x \in Z, 2x <= x: x-1, -2<= -1

Key thing: if u want to show a proposition is false, u just need to find one counter example.
but when u want to show a proposition is true, u need to proof or show it for all cases.

AND = conjunction: P ^ Q = P and Q : true if both P and Q are true
OR = disjunction: P v Q = P or Q : true if P is true and/or Q is true
XOR = exclusive or: P ⊕ Q : true if exactly one of P or Q is true
NOT = negation: \bar P or ¬P : true if P is false then ¬P is true, if P is true then ¬P is false
