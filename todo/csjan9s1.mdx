2. Suppose you have a rectangular array of pebbles, where each pebble is either red or blue.
Suppose that for every way of choosing one pebble from each column, there exsits a red pebble among the chosen ones. 
Prove that there must exsit an all red column.

If there dosn't exsit an all red column, then there exsit a way to choose a pebble from each column using only blue pebbles.

We can choose a blue from each column, therefore there exsits a way of choosing one pebble from each column with no red pebbles.


Truth table: not (P => Q) === P and not Q
Proof (by contradiction), in simple language:
1. Assume the opposite: suppose no column is all red.  
2. Then every column has at least one blue pebble.  
3. Now pick a blue pebble from each column. This gives a choice of one pebble per column that are all blue.  
4. That particular choice has no red pebble, which contradicts the given condition that every choice has a red pebble.  
5. Therefore the assumption is false, and there must be at least one column that is all red.
