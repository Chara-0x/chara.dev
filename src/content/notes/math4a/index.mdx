## Developer Experience Features

- **shadcn/ui theming**: use semantic Tailwind colors (`bg-background text-foreground`) instead of raw `dark:` styles.
- **Typography**: wrap prose in `prose` for styling instead of relying on Tailwind Typography overrides.
- **Expressive Code**: configurable code blocks with Shiki highlighting.

  ````mdx showLineNumbers=false collapse={2-42}

- **Inline highlighting**: use `rehype-pretty-code` for inline code like `console.log('Hello world!'){:js}`.
- **Class name utility**: `cn()` combines `clsx` + `tailwind-merge`.

```tsx title="src/lib/utils.ts"
import { type ClassValue, clsx } from 'clsx'
import { twMerge } from 'tailwind-merge'

export function cn(...inputs: ClassValue[]) {
  return twMerge(clsx(inputs))
}
```

- Example usage in a custom Link:

```astro title="src/components/Link.astro"
---
import { cn } from '@/lib/utils'
const { href, external, class: className, underline, ...rest } = Astro.props
---

<a
  href={href}
  target={external ? '_blank' : '_self'}
  class={cn(
    'inline-block transition-colors duration-300 ease-in-out',
    underline &&
      'underline decoration-muted-foreground underline-offset-[3px] hover:decoration-foreground',
    className,
  )}
  {...rest}
>
  <slot />
</a>
```

## User Experience Features

- **Post images**: use frontmatter `image` for Open Graph and blog display.
- **Theme selector**: place in header, use `sticky`.
- **Table of Contents**: sticky `<TableOfContents>` with `IntersectionObserver` for active heading highlight.
- **Breadcrumbs**: show hierarchy on every page (except homepage).
- **Authors**: support multiple via frontmatter → pulls info from `Authors` collection.
- **Tags**: each tag gets its own page.
