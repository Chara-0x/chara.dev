1. Differential equations are equations containing derivatives, e.g.
<span style="display: block; text-align: center; margin: 1em 0;">
$\frac{dy}{dx} = \sin(t^2)+1, \frac{d^2y}{dx^2} = y+t, \frac{\partial f(x,y)}{\partial x} = \sin(x+y)
$
</span>

In this class, we would only care about the first two equations, where the third one contains more than one independent variable. 
All of these kinds of equations are named ODE (Ordinary Differential Equations).

1. The **order** of a differential equation is given by **the order of the highest derivative** in the equation.
2. We say an n-th order differential equation $F(t, y, y', y'', \ldots, y^{(n)}) = 0$ is **linear** if it can be written as
<span style="display: block; text-align: center; margin: 1em 0;">
$a_n(t) y^{(n)} + a_{n-1}(t) y^{(n-1)} + \ldots + a_1(t) y' + a_0(t) y = g(t)$
</span>

### Separable ODE
Separable ODE can be written as
<span style="display: block; text-align: center; margin: 1em 0;">
$M(y) dy = N(t) dt$
</span>
and then take the integral for both sides.
(This is only for first-order ODE, can be either linear or nonlinear.)

###  Integrating factors
A technique used to solve the **1st order linear** ODE of the form
<span style="display: block; text-align: center; margin: 1em 0;">
$\frac{dy}{dt} + p(t) y = q(t)$
</span>
(Only for first-order linear ODE)
